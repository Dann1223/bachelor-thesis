# Bachelor Thesis Project

## Title
Design and Implementation of an Immersive Interactive Tea Culture Exhibition System Based on Unity3D

## Description
This repository contains the implementation of my bachelor thesis project.

The project focuses on the design and implementation of an immersive interactive tea culture exhibition system developed using Unity3D and C#. The system presents traditional Chinese tea culture through interactive 3D models and multimedia content.

## Main Features
- Camera roaming and scene navigation  
- Interactive 3D models of tea utensils  
- Dialogue and information display system  
- Text, audio, and video presentation  
- Background music playback  
- Interactive quiz module  

## Technology Stack
- Unity3D  
- C#  

## Project Purpose
The goal of this project is to design and implement an interactive virtual exhibition system that allows users to explore and understand traditional Chinese tea culture through immersive digital technology.
